1. Interpretando o código

Observe o código abaixo:

.container {
  background-color: lightgreen;
}

@media (max-width: 600px) {
  .container {
    background-color: lightpink;
  }
}

O que acontecerá com o fundo do .container em uma tela de 500px?


2. Completando a Media Query

Complete a media query abaixo para que o texto do corpo (body) fique com a fonte de 14px apenas em telas menores que 800px:

@media (max-width: 799px) { /* ou max-width: 800px */
  body {
    font-size: 14px;
  }
}
