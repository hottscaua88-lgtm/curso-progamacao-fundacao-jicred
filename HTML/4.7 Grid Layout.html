2. Preenchendo lacunas

Complete o código abaixo para criar um grid com 3 colunas de larguras iguais e 2 linhas com 100px de altura cada, usando gap de 10px: 

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* ou: 1fr 1fr 1fr */
  grid-template-rows: repeat(2, 100px);  /* ou: 100px 100px */
  gap: 10px;
}
